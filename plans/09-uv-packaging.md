# UV Packaging — As-Built Record

Status: **Done**. SessionIntent is installable and developable with
[uv](https://docs.astral.sh/uv/) at three levels: end users (`uv tool install`),
contributors (`uv sync` + lockfile), and tooling (INSTALL.sh, CI, docs).

## User-facing install paths

```bash
# Install from the repository (PyPI publish is a later follow-up)
uv tool install git+https://github.com/fazrigading/SessionIntent

# Run without installing
uvx --from git+https://github.com/fazrigading/SessionIntent sessionintent --help
```

Upgrade / uninstall: `uv tool upgrade sessionintent` / `uv tool uninstall sessionintent`.

## Decisions

- **Keep setuptools.** uv is build-backend-agnostic; the existing `src/` layout,
  dynamic version, and `package-data` already build fine via PEP 517.
- **PEP 735 `[dependency-groups]`** for dev tooling (`pytest`, `pytest-cov`, `ruff`,
  `mypy`, `types-PyYAML`) instead of `optional-dependencies`, so dev deps never leak
  into user installs.
- **Commit `uv.lock`.** Reproducible contributor environments; `uv sync` also installs
  the project itself in editable mode.
- **`.python-version` = `3.10`** (the `requires-python` floor). uv auto-downloads
  managed CPython 3.10 when the system Python is newer.
- **Pin the ruff rule set** (`select = ["E4", "E7", "E9", "F"]`). Ruff 0.16 broadened
  its *default* select (isort, SIM, DTZ, UP, … are on now), which turned the
  config-less repo's gate red (141 findings) without any code change. Pinning restores
  the original gate semantics and makes the gate version-stable.
- **INSTALL.sh prefers uv** (`uv tool install "$SCRIPT_DIR"`) and falls back to pip.
  The pip-only PyYAML prerequisite step is skipped when uv manages dependencies.
  Uninstall detects a uv tool install via `uv tool list`.

## Side effect: pytest-cov gap closed

`pyproject.toml` pytest `addopts` requires `pytest-cov`, but neither CI nor
CONTRIBUTING.md installed it — bare `pytest` failed on a pip-only setup. The dev group
includes `pytest-cov`, so `uv run pytest` works out of the box.

## Verification (2026-09-22)

- `uv lock` resolves cleanly (CPython 3.10.19, 20 packages).
- `uv sync` builds `.venv`; `uv run ruff check src/ tests/` and `uv run mypy src/` clean; **387 pytest passed** with coverage.
- `uv build` produces `sessionintent-0.3.3-py3-none-any.whl` + sdist.
- `uv tool install .` (isolated bin dir) → `sessionintent version` → `0.3.3` → clean uninstall.
- `bash -n INSTALL.sh` passes; the uv branch uses the same `uv tool install` mechanics verified above.
- Note: if a pip-installed `sessionintent` already exists in `~/.local/bin`,
  `uv tool install` reports `Executable already exists`; remove the old binary (or
  `pip uninstall sessionintent`) first.
